# Notebook v1과 학습 파이프라인 v2 정합성

| 항목 | Notebook v1 | Python·MLflow v2 |
|---|---|---|
| 예측 시점 | 현재 1분으로 다음 1분 예측 | 동일 |
| 입력 특성 | MELT_TEMP, MOTORSPEED, MELT_WEIGHT | 동일 |
| 시퀀스 길이 | 10 | 동일 |
| 양성 클래스 | NG=1 | 동일 |
| 타깃 규칙 | 다음 분 NG 5개 이상 | `next-minute-majority` |
| 분할 | 시간순 4개 구간 | 동일 |
| 스케일링 | train에만 fit | 동일 |
| 모델 | LSTM(32)-Dropout-Dense(16) | 동일 |
| 학습 | batch 256, 최대 30 epoch | 동일 |
| 임계값 | KPI 후보 중 F2 최대 | 동일 |
| 실험 기록 | Notebook 출력·JSON | MLflow 파라미터·지표·아티팩트 |

v2는 새로운 모델을 만드는 단계가 아니라, v1에서 검증한 실험을 명령 한 번으로 재현하고 기록할 수 있도록 모듈화한 단계다.
