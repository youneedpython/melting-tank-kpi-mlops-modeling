# v2 로컬 실행 절차

## 1. 환경 구성

```bash
conda create -n melting-tank-v2 python=3.12 -y
conda activate melting-tank-v2
python -m pip install -r requirements-dev.txt
python -m pip install -e .
```

## 2. 데이터 배치

`melting_tank.csv`를 `data/raw/`에 복사한다. 원본 데이터는 Git에 커밋하지 않는다.

## 3. 검사

```bash
pytest -q
ruff check .
```

## 4. MLflow 실행

```bash
docker compose up -d mlflow
```

브라우저에서 `http://127.0.0.1:5000`을 확인한다. Docker를 사용하지 않으면 환경변수를 지정하지 않고 로컬 파일 저장 방식으로도 학습할 수 있다.

## 5. Smoke 학습

```bash
python -m melting_tank.train --epochs 1 --sample-minutes 1000 --run-name smoke-v2
```

## 6. 전체 학습

```bash
python -m melting_tank.train --run-name baseline-v2-full
```

`artifacts/`와 MLflow에서 파라미터, 학습 이력, 평가 지표와 배포 승인 여부를 확인한다. v2의 승인 판정은 기록용이며 모델 등록과 서빙은 수행하지 않는다.
