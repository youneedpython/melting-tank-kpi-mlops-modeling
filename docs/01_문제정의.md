# 용해탱크 품질예측 문제 정의

## 예측 질문

현재 1분 동안 수집된 10개의 센서 관측값으로 다음 1분의 관측값 10개 중 NG가 5개 이상 발생할지를 예측한다.

## 입력과 출력

- 입력 특성: MELT_TEMP, MOTORSPEED, MELT_WEIGHT
- 입력 모양: `(표본 수, 10 timestep, 3 feature)`
- 출력: 다음 1분 NG 확률
- 양성 클래스: NG=1, OK=0

## 타깃 정의

다음 1분의 관측값 10개 중 NG가 5개 이상이면 해당 분을 NG로 정의한다. 이는 한 건의 순간적인 NG보다 지속적인 품질 이상을 탐지하려는 교육용 정의이며, 실제 현장에서는 품질 담당자와 합의해야 한다.

## 데이터 누수 방지

시계열 순서를 유지하여 학습·검증·테스트를 분리한다. INSP는 실제 예측 시점에 사용할 수 있는지 불분명하므로 입력에서 제외한다. MinMaxScaler는 학습 데이터에만 적합한 후 검증·테스트 데이터에 적용한다.
