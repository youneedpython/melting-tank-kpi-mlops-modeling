# 모델 평가 및 배포 판단 기준

## 핵심 KPI

| 지표 | 기준 | 의미 |
|---|---:|---|
| NG Recall | 0.90 이상 | 실제 NG 중 탐지한 비율 |
| NG Precision | 0.60 이상 | NG 경보 중 실제 NG 비율 |
| 정상 구간 오경보율 | 0.05 이하 | 정상 데이터에 불필요한 경보를 낸 비율 |

## 임계값 선택

검증 데이터에서만 임계값을 탐색한다. NG Recall과 NG Precision 기준을 만족하는 후보 중 F2-score가 가장 높은 임계값을 선택한다. 조건을 만족하는 임계값이 없으면 F2-score가 가장 높은 값을 진단용으로 선택하되, 모델은 배포 부적합으로 판단한다.

## 최종 평가

선택한 임계값을 변경하지 않고 NG 테스트 구간과 정상 테스트 구간에 적용한다. 세 KPI를 모두 통과해야 배포 후보로 판단한다.   
본 모델링 저장소에서는 배포 가능 여부만 판정하며,
실제 모델 서빙과 배포는 별도의 serving 저장소에서 수행한다.
